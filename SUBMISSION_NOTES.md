# Devpost submission notes

Before submitting, make sure the claims in your Devpost description match what you can demonstrate.

## Recommended project media
Use a screenshot of the running application, not only a static mockup.

## Before recording your demo
- Run the app from a clean environment using the README.
- Confirm the `/api/health` response.
- If demonstrating PayPal, configure sandbox REST credentials and use a sandbox buyer account.
- Demonstrate a successful checkout and capture, not just a button click.
- If you do not configure the OpenAI API, describe the assistant as a local demo assistant rather than claiming a live LLM integration.
- The project currently uses illustrative in-memory invoices; say so clearly.
- Do not include credentials in your public repository or screen recording.
